NAME TAG MAKER - DESKTOP APP SETUP (one time, about 5 minutes)

1. Go to https://app.netlify.com and sign in (same account as printpluto.ca).
2. Add new site > Deploy manually > drag THIS WHOLE FOLDER onto the page.
3. Site settings > Change site name > e.g.  nametags-pp  (any free name).
   Your app is now at https://nametags-pp.netlify.app
4. Open that link in Chrome or Edge.
   Chrome: click the install icon at the right end of the address bar (a monitor with a down arrow) > Install.
   Edge:   ... menu > Apps > Install this site as an app.
5. It now opens from the Start menu / taskbar in its own window and works offline.
   Right-click its taskbar icon > Pin to taskbar.

NOTES
- The installed app keeps its own saved models, fonts and positions, so add your
  tag models and fonts once inside the app.
- "Choose save folder" works in the app too, so files save straight to your orders folder.
- To update the app later: drag the new folder onto the same Netlify site (Deploys tab).
  The app picks up the update the next time it opens with internet.
- The page has nothing private in it, but anyone with the link could use it.
  Pick a site name nobody would guess if that matters.
