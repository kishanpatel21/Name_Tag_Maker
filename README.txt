NAME TAG MAKER - DESKTOP APP

Live app: https://kishanpatel21.github.io/Name_Tag_Maker/
Hosted free on GitHub Pages (Settings > Pages > main branch, / root).

INSTALL (one time)
- Open the link in Chrome or Edge.
  Chrome: click the install icon at the right end of the address bar > Install.
  Edge:   ... menu > Apps > Install this site as an app.
- It opens from the Start menu / taskbar in its own window and works offline.
  Right-click its taskbar icon > Pin to taskbar.

NOTES
- The installed app keeps its own saved models, fonts and positions, so add your
  tag models and fonts once inside the app.
- "Choose save folder" works in the app too, so files save straight to your orders folder.

UPDATING
- Replace index.html in this repo (Add file > Upload files > Commit changes).
- GitHub Pages republishes in a minute or two; the installed app picks up the
  update the next time it opens with internet.

FILES
- index.html            the whole tool (three.js, opentype.js, JSZip from CDNs)
- manifest.webmanifest  app name, icons, colours for installing
- sw.js                 offline cache
- icon-192.png, icon-512.png
